# Поиск-остров

Один поиск для всего: программы, файлы, заметки Obsidian, калькулятор, интернет.
Открывается кнопкой с лупой на HyprPanel или **SUPER+SHIFT+F**: кнопка
раздувается в окно поиска, по Esc сжимается обратно.

## Как пользоваться

| Что | Как |
|---|---|
| открыть / закрыть | кнопка на панели, SUPER+SHIFT+F, Esc, щелчок мимо |
| выбрать | ↑ ↓ (или Tab), мышью — наведением |
| открыть выбранное | Enter или щелчок |
| показать файл в папке | Shift+Enter |
| закрепить / открепить | Ctrl+P или правый щелчок по строке |
| переставить закреплённое | Ctrl+↑ / Ctrl+↓ при пустом запросе |
| посчитать | `12*7+1`, `2^10`, `(2+3)*4,5` — Enter копирует ответ |
| открыть сайт | `github.com` — адрес откроется, остальное ищется в Google |

## Закреплённое

При пустом запросе показывается то, что закреплено (сначала — Firefox,
Obsidian, kitty). Закрепить можно программу, файл, папку или заметку.
Список лежит в `~/.config/spotlight/pinned.json`; удалённая программа или
файл просто не показываются.

## Файлы

| Файл | Что делает |
|---|---|
| `spotlight.py` | окно, анимация, клавиши; живёт в фоне |
| `sources.py` | откуда результаты: программы, файлы, калькулятор, интернет |
| `toggle` | открыть/закрыть (его зовут клавиша и кнопка) |

Снаружи:

- `~/.config/hypr/hyprland.conf` — `bind` на SUPER+SHIFT+F, `exec-once` с
  `--daemon`, `layerrule` для размытия (ищи слово `spotlight`).
- `~/.config/hyprpanel/modules.json` — кнопка `custom/search` и её
  невидимый двойник `custom/searchpad`; `config.json` — порядок
  `search, clock, searchpad` в середине панели. Середина центрируется
  целиком, и без двойника справа часы стояли бы правее центра.
- `~/.config/hyprpanel/modules.scss` — нулевой отступ у кнопки (иначе лупа
  не по центру) и прозрачность двойника.

## Почему так устроено

- **Работает в фоне.** Иначе каждое открытие ждало бы загрузки питона и
  GTK. `toggle` дёргает уже запущенную программу через `gdbus` — это
  миллисекунды. Если программы нет, `toggle` её запустит.
- **Остров рисуется вручную**, а не CSS-анимацией: на каждом кадре меняется
  только картинка, разметка не пересчитывается. Замер на T460: 16–17 мс на
  кадр, то есть ровные 60 кадров в секунду.
- **Анимация — пружина.** Передумал на полпути — остров разворачивается с той
  же скоростью, без рывка.
- **Esc и Enter — на отпускании.** Закрыться на нажатии — зажатая клавиша
  уйдёт в окно под нами (так уже выкидывало YouTube из полного экрана).
- **Размытие задаёт Hyprland**, правилом `layerrule`. GTK 4.24 пытается
  управлять им сам и сообщает «размывать нигде», поэтому в программе
  выключен протокол `ext_background_effect_manager_v1`.
- **Файлы ищутся по списку в памяти**, который `fd` пересобирает при каждом
  открытии (~0,07 с). Скрытые папки и то, что в `.gitignore`, не попадают.
  plocate не подошёл: обновляется раз в сутки и медленный на коротких
  запросах.

## Если кнопка на панели съехала

Остров стартует ровно с кнопки, её место записано в `BUTTON` в начале
`spotlight.py`. Поменял панель (шрифт, отступы, порядок модулей) — кнопка
уедет, и анимация начнётся рядом. Перемерить: запустить с
`SPOTLIGHT_DEBUG=1`, вызвать действие `pose` с `0.0001` и сравнить скриншот
с кнопкой.

## Отладка

```sh
# перезапустить с замерами кадров в журнале
kill $(busctl --user status dev.bogdan.Spotlight | sed -n 's/^PID=//p')
SPOTLIGHT_DEBUG=1 python3 ~/.local/share/spotlight/spotlight.py --daemon

# открыть с готовым запросом (без клавиатуры)
gdbus call --session --dest dev.bogdan.Spotlight --object-path /dev/bogdan/Spotlight \
  --method org.gtk.Actions.Activate query "[<'fire'>]" '{}'
```

## Откат

```sh
cp -p ~/.config/hypr/hyprland.conf.bak-2026-10-07-spotlight ~/.config/hypr/hyprland.conf
cp -p ~/.config/hyprpanel/modules.json.bak-2026-10-07-spotlight ~/.config/hyprpanel/modules.json
cp -p ~/.config/hyprpanel/config.json.bak-2026-10-07-spotlight ~/.config/hyprpanel/config.json
cp -p ~/.config/hyprpanel/modules.scss.bak-2026-10-07-spotlight ~/.config/hyprpanel/modules.scss
hyprctl reload
# панель перезапустить (раскладку она на лету не перечитывает),
# программу остановить:
kill $(busctl --user status dev.bogdan.Spotlight | sed -n 's/^PID=//p')
```

Старая строка поиска осталась в `~/.local/share/websearch` нетронутой.
